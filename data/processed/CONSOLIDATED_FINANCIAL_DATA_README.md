# Consolidated Financial Data Structure

This document describes the consolidated financial data model that unifies data from three sources:
1. **IRS Form 990 Filings** - Tax filings with the IRS
2. **Audited Financial Statements** - Annual audited financial reports
3. **Budget Data** - Both draft and final approved budgets

## Purpose

The consolidated data model allows for:
- **Budget vs Actual Analysis**: Compare budgeted amounts to actual results
- **Source Comparison**: Compare values across 990 filings and audited statements
- **Unified Reporting**: Single source of truth for all financial reporting
- **Historical Tracking**: Track financial performance across multiple years

## Data Structure

### ConsolidatedFinancialData
The top-level structure containing all financial data:

```json
{
  "metadata": {
    "version": "1.0.0",
    "last_updated": "2024-01-15T10:00:00Z",
    "sources": ["990", "audited", "budget"],
    "description": "Consolidated financial data from all sources"
  },
  "years": [...],
  "years_available": [2014, 2015, 2016, ...],
  "latest_year": 2024
}
```

### ConsolidatedFinancialYearData
Data for a single year from all sources:

```json
{
  "year": 2023,
  "form_990": { /* FinancialYearData from 990 filing */ },
  "audited": { /* AuditedFinancialYearData from audited statements */ },
  "budget_draft": { /* BudgetData - draft version */ },
  "budget_final": { /* BudgetData - final approved version */ },
  "revenue_variance_draft": 125000.0,
  "revenue_variance_final": 98000.0,
  "expense_variance_draft": -45000.0,
  "expense_variance_final": -32000.0
}
```

## Field Alignment

All three data sources use aligned field names where possible:

### Revenue Fields
- `total_revenue` - Total revenue for the year
- `program_service_revenue` - Revenue from program services
- `contributions_grants` - Contributions and grants
- `investment_income` - Investment income
- `other_revenue` - Other revenue sources
- `membership_dues` - Membership dues revenue
- `meetings_conferences` - Meetings and conferences revenue
- `education_certification` - Education and certification revenue
- `project_management_fees` - Project management fees

### Expense Fields
- `total_expenses` - Total expenses for the year
- `salaries_compensation` - Salaries and compensation
- `other_expenses` - Other operating expenses
- `total_program_services` - Total Program Services expenses
- `total_supporting_services` - Total Supporting Services expenses

### Balance Sheet Fields
- `total_assets` - Total assets
- `total_liabilities` - Total liabilities
- `net_assets` - Net assets

### Functional Expenses (Audited & Budget only)
- `functional_expenses` - Breakdown by expense category with Program/Supporting split

## Data Source Priority

When multiple sources are available, the system uses this priority:

1. **For Actuals**: Audited financial statements > IRS Form 990
2. **For Budgets**: Final budget > Draft budget

Helper methods on `ConsolidatedFinancialYearData`:
- `get_total_revenue(prefer_audited=True)` - Gets revenue, preferring audited
- `get_total_expenses(prefer_audited=True)` - Gets expenses, preferring audited
- `get_net_income(prefer_audited=True)` - Calculates net income

## Budget Variance Calculation

Variances are automatically calculated when both actual and budget data exist:

- `revenue_variance_draft` = Actual Revenue - Draft Budget Revenue
- `revenue_variance_final` = Actual Revenue - Final Budget Revenue
- `expense_variance_draft` = Actual Expenses - Draft Budget Expenses
- `expense_variance_final` = Actual Expenses - Final Budget Expenses

Positive variance = over budget (revenue) or under budget (expenses)
Negative variance = under budget (revenue) or over budget (expenses)

## Adding Budget Data

To add budget data for a year:

```python
from app.consolidated_financial_service import ConsolidatedFinancialService
from app.models import BudgetData

service = ConsolidatedFinancialService()

budget = BudgetData(
    year=2024,
    version="final",
    total_revenue=12000000.0,
    total_expenses=11500000.0,
    # ... other fields
)

service.add_budget_data(2024, budget, is_final=True)
```

## API Endpoints

- `GET /api/consolidated-financial/data` - Get all consolidated data
- `GET /api/consolidated-financial/year/{year}` - Get data for specific year
- `GET /api/consolidated-financial/budget-vs-actual` - Get budget vs actual chart data
- `POST /api/consolidated-financial/refresh` - Refresh consolidated data from sources

## File Location

The consolidated data is stored at:
`data/processed/consolidated_financial_data.json`

This file is automatically generated from the source data (990, audited, budget) and should be regenerated when source data changes.
